## Projets

Des projets où j'ai essayé de suivre une vraie démarche, du besoin jusqu'au résultat, pas juste un script qui tourne.

- **[Scoring de propension B2B](https://github.com/ATEYABA-K/scoring-prospects-b2b)** — un modèle pour prioriser les prospects à recontacter en premier, sur un jeu de données public faute d'avoir accès à de vraies données commerciales. J'y explique aussi une erreur que j'ai repérée et corrigée en cours de route.
- **[Adoption de l'IA par les PME françaises](https://github.com/ATEYABA-K/adoption-ia-pme-france)** — à partir des chiffres Insee, je regarde si les PME rattrapent leur retard sur l'IA. L'écart avec les grandes entreprises a presque triplé en deux ans (16 à 43 points, 2023-2025).
- **[Automatisation d'un pipeline de reporting](https://github.com/ATEYABA-K/automatisation-reporting-insee)** — le projet Adoption IA PME ci-dessus demandait un nettoyage manuel des données Insee ; ici j'ai automatisé les mêmes étapes (GitHub Actions) pour ne pas avoir à les refaire à chaque nouvelle édition du fichier.
- **[Évolution des prix à la consommation en France](https://github.com/ATEYABA-K/analyse-ipc-france-covid)** — données Insee sur l'inflation (2019-2026) par poste (global, alimentation, énergie), confrontées au SMIC pour évaluer le pouvoir d'achat réel.
- **[Note de cadrage — scoring IA de risque d'attrition](https://github.com/ATEYABA-K/note-cadrage-scoring-ia-pme)** — l'exercice qu'on montre le moins souvent : cadrer un projet data avant de coder (objectifs, parties prenantes, risques), sur un cas fictif.

**Exercices plus courts, pour combler des manques précis de mon portfolio :**
- **[Analyse SQL des ventes](https://github.com/ATEYABA-K/analyse-sql-ventes-musique)** — jointures, agrégations et fonctions fenêtre sur une base de démonstration.
- **[Suivi de projet (Excel)](https://github.com/ATEYABA-K/suivi-projet-dashboard-kpi)** — suite directe de la note de cadrage ci-dessus : simuler le pilotage du même projet une fois lancé (jalons, budget, avancement).
- **[Analyse du churn client](https://github.com/ATEYABA-K/analyse-churn-telco)** — dans quels segments de clients le risque de départ est concentré, sans passer par un modèle prédictif.
